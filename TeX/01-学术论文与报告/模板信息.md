# 学术论文模板

> 中文论文 / 课程报告骨架：摘要、数学、图表、引用、附录一应俱全，`【】` 占位即换即用。

## 基本信息

| 项目 | 内容 |
|---|---|
| 分类 | 学术论文与报告 |
| 入口文件 | `学术论文模板.tex` |
| 文档类 | `article`（12pt, a4paper） |
| 编译器 | **XeLaTeX**（中文） |
| 参考文献 | 无外部 `.bib` 依赖 |
| 许可 | 本库自有，MIT |

## 编译

```powershell
cd "01-学术论文与报告"
latexmk -xelatex 学术论文模板.tex
# 或不用 latexmk：xelatex 连跑两遍
```

## 用法

1. 复制 `学术论文模板.tex` 到你的项目；
2. 替换所有 `【】` 占位（标题、作者、摘要……）；
3. XeLaTeX 编译即可。
