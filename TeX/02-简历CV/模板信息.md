# 简历模板

> 单页紧凑中文简历：教育背景、项目经历、获奖、技能四段式。

## 基本信息

| 项目 | 内容 |
|---|---|
| 分类 | 简历 CV |
| 入口文件 | `简历模板.tex` |
| 文档类 | `article`（11pt, a4paper） |
| 编译器 | **XeLaTeX**（中文） |
| 许可 | 本库自有，MIT |

## 编译

```powershell
cd "02-简历CV"
latexmk -xelatex 简历模板.tex
```

## 用法

1. 复制 `简历模板.tex`；
2. 替换 `【】` 占位内容；
3. XeLaTeX 编译，单页输出。
