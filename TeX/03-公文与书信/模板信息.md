# 公文与书信

> 两个独立模板：正式公文排版 + 中文书信 / 邮件。

## 基本信息

| 项目 | 内容 |
|---|---|
| 分类 | 公文与书信 |
| 入口文件 | `公文模板.tex`、`书信模板.tex`（各自独立编译） |
| 文档类 | `article`（12pt, a4paper） |
| 编译器 | **XeLaTeX**（中文） |
| 许可 | 本库自有，MIT |

## 编译

```powershell
cd "03-公文与书信"
latexmk -xelatex 公文模板.tex
latexmk -xelatex 书信模板.tex
```

## 用法

复制需要的那个文件，替换 `【】` 占位即可。

## 目录说明

| 文件 | 说明 |
|---|---|
| `公文模板.tex` | 正式公文（标题、主送、正文、落款） |
| `书信模板.tex` | 中文书信 / 邮件 |
| `_预览/公文模板.pdf`、`.png` | 公文成品首页 |
| `_预览/书信模板.pdf`、`.png` | 书信成品首页 |

## 依赖

`ctex`/`xeCJK`。TeX Live 全量安装即可满足。
