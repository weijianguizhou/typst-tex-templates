# 演讲稿模板

> 学术演讲 / 答辩讲稿骨架；另附 Markdown 快速版，可直接转 Word。

## 基本信息

| 项目 | 内容 |
|---|---|
| 分类 | 演讲稿 |
| 入口文件 | `演讲稿模板.tex` |
| 文档类 | `article`（12pt, a4paper） |
| 编译器 | **XeLaTeX**（中文） |
| 许可 | 本库自有，MIT |

## 编译

```powershell
cd "04-演讲稿"
latexmk -xelatex 演讲稿模板.tex
```

## 目录说明

| 文件 | 说明 |
|---|---|
| `演讲稿模板.tex` | LaTeX 讲稿（标题、分节、计时提示） |
| `演讲稿模板.md` | Markdown 快速版，适合先写稿后排版 |
| `_预览/预览.pdf`、`_预览/预览.png` | 本库实测编译的成品首页 |

## 依赖

`ctex`/`xeCJK`。TeX Live 全量安装即可满足。
