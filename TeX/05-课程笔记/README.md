# 05-课程笔记

两套可独立使用的 LaTeX 笔记模板，各自带 `模板信息.md` 与 `_预览/`。

## 1. 李思风极简笔记 — 默认

「李思风」极简学术笔记：`book` 类中文笔记，细边框圆角定理盒、行内加粗标签，
内置 12 款可切换封面。**XeLaTeX 编译两遍。**

- 入口：[`李思风极简笔记/课程笔记模板.tex`](李思风极简笔记/课程笔记模板.tex)
- 说明：[`李思风极简笔记/模板信息.md`](李思风极简笔记/模板信息.md)
- 封面效果：[`李思风极简笔记/封面/封面模板索引.md`](李思风极简笔记/封面/封面模板索引.md)

## 2. textbook 分栏讲义

基于自定义文类 `textbook.cls` 的教材 / 长篇讲义：分栏、多主题框、定理环境、
参考文献，含中 / 英两个主文件。

- 中文入口：[`textbook分栏讲义/cn-mynotes.tex`](textbook分栏讲义/cn-mynotes.tex)
- 英文入口：[`textbook分栏讲义/mynote.tex`](textbook分栏讲义/mynote.tex)
- 说明：[`textbook分栏讲义/模板信息.md`](textbook分栏讲义/模板信息.md)
