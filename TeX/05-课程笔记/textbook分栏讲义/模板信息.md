# textbook 分栏讲义

> 基于自定义文类 `textbook.cls` 的教材 / 长篇讲义模板：分栏、多主题框、定理环境、参考文献，含中 / 英两个主文件。

## 基本信息

| 项目 | 内容 |
|---|---|
| 分类 | 课程笔记 |
| 入口文件 | `cn-mynotes.tex`（中文）、`mynote.tex`（英文） |
| 文档类 | `textbook.cls`（`lang=cn` → `ctexbook`；`lang=en` → `book`） |
| 编译器 | **XeLaTeX，编译两遍**（有目录 / 参考文献） |
| 中文字体 | 默认回退 SimSun / SimHei / KaiTi / FangSong（Windows 自带）；自备 `fonts/` 方正字库时自动切换原配置 |
| 许可 | 本库自有，MIT |

## 编译

```powershell
cd "05-课程笔记\textbook分栏讲义"
latexmk -xelatex cn-mynotes.tex
latexmk -xelatex mynote.tex
```

## 字体说明

- **开箱即用**：未装方正字库时，`textbook.cls` 自动回退到系统自带中文字体（SimSun 等），可直接编译。
- **原配置**：如需原作者的方正字体效果，把字库放进 `fonts/` 目录（文件名以 `textbook.cls` 字体块中列出的为准），重新编译即自动启用。

## 目录说明

| 文件 / 目录 | 说明 |
|---|---|
| `cn-mynotes.tex` | 中文主文件（示例：泛函分析笔记） |

| `textbook.cls` | 文类：分栏、多主题框、定理环境、字体配置 |
| `摘要.tex`、`导言.tex`、`1.tex`…`5.tex`、`Appendix.tex` | 中文示例章节 |
| `chapter1.tex`…`chapter4.tex` | 英文示例章节（内容彼此相同，可按需精简） |
| `main.bib` | 参考文献 |
| `images/` | 封面与插图素材 |
| `宁夏大学图标.png` | 示例用校标素材 |
| `_预览/cn-mynotes.pdf`、`.png` | 中文版成品首页 |
| `_预览/mynote.pdf`、`.png` | 英文版成品首页 |
