# 李思风极简笔记

> 「李思风」极简学术笔记：`book` 类中文笔记，细边框圆角定理盒、行内加粗标签，内置 12 款可切换封面。

## 基本信息

| 项目 | 内容 |
|---|---|
| 分类 | 课程笔记 |
| 入口文件 | `课程笔记模板.tex` |
| 文档类 | `book`（11pt, a4paper, openany） |
| 编译器 | **XeLaTeX，编译两遍**（有目录） |
| 中文字体 | `ctex` 的 `fontset=fandol`（TeX Live 自带，无需另装） |
| 许可 | 本库自有，MIT |

## 编译

```powershell
cd "05-课程笔记\李思风极简笔记"
latexmk -xelatex 课程笔记模板.tex
```

## 用法

1. 把整个 `李思风极简笔记` 目录复制到新项目；
2. 打开 `课程笔记模板.tex`，替换所有 `【】`；
3. 换封面：改主文件里的 `\input{封面/cover_*}`，**一次只启用一行**，12 款效果见 `封面/封面模板索引.md`；
4. XeLaTeX 编译两遍。

> 章节文件顶部保留 `% !TeX root = ../课程笔记模板.tex`，否则单独编译章节会报假错误。

## 目录说明

| 文件 / 目录 | 说明 |
|---|---|
| `课程笔记模板.tex` | 主文件（替换所有 `【】` 即可用） |
| `preamble.tex` | 样式：字体 / 配色 / 定理·定义·例题环境 |
| `封面/` | 12 款封面 + `封面模板索引.md` |
| `章节示例/` | 前言、绪论、第一章示例、附录 |
| `说明文档/` | 符号约定与工作要求（示例规范，可删） |
| `_预览/预览.pdf`、`_预览/预览.png` | 本库实测编译的成品首页 |
