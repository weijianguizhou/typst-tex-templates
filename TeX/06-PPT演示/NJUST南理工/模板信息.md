# NJUST 南理工 Beamer

> 南理工紫极简 Beamer：校徽、中文定理环境、三线表，16:9。版式源自 PKU 极简 Beamer。

## 基本信息

| 项目 | 内容 |
|---|---|
| 分类 | PPT 演示 |
| 入口文件 | `NJUST-slides.tex` |
| 文档类 | `beamer`（10pt, aspectratio=169） |
| 样式文件 | `NJUST.sty`（同目录，主题色 `njust_blue`） |
| 编译器 | **XeLaTeX，编译两遍**（目录 / 引用） |
| 参考文献 | `ref.bib` |
| 许可 | 见 `README.md`（上游 PKU 版 License 附在 `../PKU极简/LICENSE`） |

## 编译

```powershell
cd "06-PPT演示\NJUST南理工"
latexmk -xelatex NJUST-slides.tex
```

## 用法

1. 复制整个目录（`NJUST.sty`、`logo/`、`image/` 必须与主文件同目录）；
2. 改 `NJUST-slides.tex` 里的标题页与帧内容；
3. XeLaTeX 编译两遍。

## 目录说明

| 文件 / 目录 | 说明 |
|---|---|
| `NJUST-slides.tex` | 主文件（示例帧可直接改） |
| `NJUST.sty` | 主题：配色、定理盒、页眉页脚 |
| `ref.bib` | 参考文献 |
| `logo/` | 校徽图片 |
| `image/` | 示例插图与效果截图 |
| `README.md` | 上游说明 |
| `_预览/预览.pdf`、`_预览/预览.png` | 本库实测编译的成品首页 |
