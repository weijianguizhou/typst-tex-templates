# PKU 极简 Beamer

> 北大极简 Beamer 原版，16:9，NJUST / 钱学森学院两版的版式来源。

## 基本信息

| 项目 | 内容 |
|---|---|
| 分类 | PPT 演示 |
| 入口文件 | `main.tex` |
| 文档类 | `beamer`（10pt, aspectratio=169） |
| 样式文件 | `PekingU.sty`（同目录，主题色 `peking_blue`） |
| 编译器 | **XeLaTeX，编译两遍**（目录 / 引用） |
| 参考文献 | `ref.bib` |
| 许可 | 见 `LICENSE` |

## 编译

```powershell
cd "06-PPT演示\PKU极简"
latexmk -xelatex main.tex
```

## 用法

1. 复制整个目录（`PekingU.sty`、`Figures/` 必须与主文件同目录）；
2. 改 `main.tex` 里的标题页与帧内容；
3. XeLaTeX 编译两遍。

## 目录说明

| 文件 / 目录 | 说明 |
|---|---|
| `main.tex` | 主文件（示例帧可直接改） |
| `PekingU.sty` | 主题：配色、定理盒、页眉页脚 |
| `ref.bib` | 参考文献 |
| `Figures/` | 校徽与示例图片 |
| `docs/` | 上游自带的效果预览图 |
| `README.md`、`LICENSE` | 上游说明与许可 |
| `clean.sh` | 上游清理脚本（Linux / macOS 用） |
| `_预览/预览.pdf`、`_预览/预览.png` | 本库实测编译的成品首页 |
