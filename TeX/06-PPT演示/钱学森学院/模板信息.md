# 钱学森学院 Beamer

> 钱院洋红 Beamer：院徽组合标识，结构与 NJUST 版一致，16:9。版式源自 PKU 极简 Beamer。

## 基本信息

| 项目 | 内容 |
|---|---|
| 分类 | PPT 演示 |
| 入口文件 | `QXC-slides.tex` |
| 文档类 | `beamer`（10pt, aspectratio=169） |
| 样式文件 | `QXC.sty`（同目录，主题色 `qxc_blue`） |
| 编译器 | **XeLaTeX，编译两遍**（目录 / 引用） |
| 参考文献 | `ref.bib` |
| 许可 | 见 `README.md`（上游 PKU 版 License 附在 `../PKU极简/LICENSE`） |

## 编译

```powershell
cd "06-PPT演示\钱学森学院"
latexmk -xelatex QXC-slides.tex
```

## 用法

1. 复制整个目录（`QXC.sty`、`logo/`、`figure/`、`image/` 必须与主文件同目录）；
2. 改 `QXC-slides.tex` 里的标题页与帧内容；
3. XeLaTeX 编译两遍。

## 目录说明

| 文件 / 目录 | 说明 |
|---|---|
| `QXC-slides.tex` | 主文件（示例帧可直接改） |
| `QXC.sty` | 主题：配色、定理盒、页眉页脚 |
| `ref.bib` | 参考文献 |
| `logo/`、`figure/` | 院徽与组合标识图片 |
| `image/` | 示例插图与效果截图 |
| `tools/` | 辅助脚本（如 `build_logo.py`） |
| `README.md` | 上游说明 |
| `_预览/预览.pdf`、`_预览/预览.png` | 本库实测编译的成品首页 |
