# 我的课程笔记模板（inelegant-note）

中文课程笔记模板，最初由本库作者在实际课程笔记中整理，后打包为独立 `.typ` 文件。

## 特点

- 基于 `@preview/inelegant-note:0.9.1`，保留 Elegant Book 风格；
- 五色内容盒：定义、定理、例、特征、公式；
- 注 / 重点 / 注意 / 引用四种注记盒；
- 三线表、封面、格言页、前言、目录、按章重置图表编号；
- 字体按思源宋体 / 思源黑体 / Noto / SimHei / SimSun 逐级回退。

## 使用

```powershell
typst compile 笔记模板1.typ 笔记.pdf
```

首次编译会自动下载 `inelegant-note` 及其依赖。全文搜索 `【】` 替换为你的内容。

## 文件

- `笔记模板1.typ`：主文件；
- `笔记模板1.pdf`：已编译的 232 行示例；
- 上游样式包见同级的 `../inelegant-note/`。
